# ☕📚 Projeto - Café Lumière

Um planejamento de *site moderno e responsivo* para uma *cafeteria literária* que une o aconchego do café com o universo dos livros. A expectativa do desenvolvimento do projeto tem foco em um design elegante, uma identidade visual sofisticada e experiência mobile-first.

---

## ✨ Sobre o projeto

O *Café Lumière* é um planejamento de um projeto fictício que consiste na criação de um site de uma cafeteria temática onde os clientes podem:
- Conhecer o ambiente da cafeteria
- ⁠Explorar o cardápio
- ⁠Visualizar e comprar produtos
- ⁠Ter uma experiência visual inspirada em literatura e sofisticação
- ⁠Navegar de forma fluida em qualquer dispositivo (mobile first)

## 🎯 Objetivos

- Planejar um site visualmente elegante e moderno
- ⁠Aplicar o conceito de Mobile First
- ⁠Desenvolver uma identidade visual consistente
- ⁠Trabalhar organização de layout e hierarquia visual
- ⁠Simular um projeto real de marca

## 🧱 Tecnologias utilizadas

- HTML
- CSS
- Google Fonts
- Canva
- Visual Studio Code
- GitHub

## 📱 Responsividade

O site tem planeja seguir o conceito Mobile First, garantindo:
- Boa leitura em telas pequenas
- ⁠Layout adaptável para tablets e desktops
- ⁠Imagens e elementos ajustados automaticamente
- ⁠Navegação simples e intuitiva
